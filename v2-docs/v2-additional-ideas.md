# Seiling Buidlbox v2 Additional Ideas

## Overview
Brainstorm beyond core roadmap; 30+ ideas across pillars. Prioritized via matrix: High/Med/Low Impact vs Effort. Focus: Innovative, feasible extensions. Review quarterly; integrate top via bounties.

## Impact/Effort Matrix
- **High Impact/Low Effort**: Quick wins (e.g., more templates).
- **High Impact/Med Effort**: Strategic (e.g., mobile app).
- **High Impact/High Effort**: Moonshots (e.g., VR dev).

- **Web3 Auth**: Wallet-based login for all services (Med/Low).
