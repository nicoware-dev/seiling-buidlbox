# Expanded Capabilities - Complete Guide

## Overview

The Expanded Capabilities package adds powerful observability, monitoring, privacy, backend services, voice integration, and reverse proxy options to Seiling Buidlbox v2. All services are optional and can be enabled individually via `ENABLE_*` flags.

## Services Overview

### 🔍 Observability & Monitoring

1. **[Langfuse](langfuse.md)** - LLM Observability
   - Trace and monitor LLM calls across all agents
   - Track costs and token usage
   - Debug prompts and responses
   - Port: 8004

2. **[Prometheus/Grafana](prometheus-grafana.md)** - System Monitoring
   - Collect metrics from all services
   - Visualize with Grafana dashboards
   - Alert on service issues
   - Ports: 9090 (Prometheus), 8005 (Grafana)

### 🔒 Privacy & Search

3. **[SearXNG](searxng.md)** - Privacy-Focused Search
   - Meta-search engine with privacy protection
   - Sei-specific search engines (SeiScan, SeiTrace)
   - API access for agents
   - Port: 8006

### 💾 Backend Services

4. **[Supabase](supabase.md)** - Backend-as-a-Service
   - Full BaaS stack (Auth, Storage, Realtime, Database)
   - User management
   - File storage
   - Real-time subscriptions
   - Ports: 8000 (API), 8007 (Studio)

### 🎤 Voice Integration

5. **[Kokoro/Chatterbox](kokoro-chatterbox.md)** - Voice/Audio
   - Text-to-Speech (TTS)
   - Automatic Speech Recognition (ASR)
   - Voice-enabled chat interface
   - Port: 3008

### 🌐 Reverse Proxy & Tunneling

6. **[Caddy](caddy-cloudflared.md)** - Modern Reverse Proxy
   - Automatic HTTPS with Let's Encrypt
   - Simple configuration
   - Security headers
   - Ports: 80, 443

7. **[Cloudflared](caddy-cloudflared.md)** - Zero-Trust Tunneling
   - Secure tunnels without public IPs
   - Cloudflare global network
   - Easy remote access

## Quick Start

### Enable All Services

```bash
# Edit .env file
ENABLE_LANGFUSE=yes
ENABLE_PROMETHEUS=yes
ENABLE_SEARXNG=yes
ENABLE_SUPABASE=yes
ENABLE_KOKORO=yes
ENABLE_CADDY=yes
ENABLE_CLOUDFLARED=no  # Optional

# Deploy
./bootstrap.sh
```

### Enable Individual Services

Enable only the services you need:

```bash
# Just observability
ENABLE_LANGFUSE=yes
ENABLE_PROMETHEUS=yes

# Just backend services
ENABLE_SUPABASE=yes

# Just voice
ENABLE_KOKORO=yes
```

## Configuration

All services follow the standard Seiling Buidlbox configuration pattern:

1. **Enable via `.env`**: Set `ENABLE_SERVICE=yes`
2. **Automatic setup**: Bootstrap script handles configuration
3. **Secret generation**: Secrets auto-generated (can be customized)
4. **Health checks**: Built-in health monitoring

### Environment Variables

See individual service documentation for complete variable lists. Key variables:

```bash
# Langfuse
ENABLE_LANGFUSE=no
LANGFUSE_NEXTAUTH_SECRET=<auto-generated>
CLICKHOUSE_PASSWORD=<auto-generated>
MINIO_ROOT_PASSWORD=<auto-generated>

# Prometheus/Grafana
ENABLE_PROMETHEUS=no
GRAFANA_ADMIN_PASSWORD=<auto-generated>

# SearXNG
ENABLE_SEARXNG=no
SEARXNG_SECRET_KEY=<auto-generated>

# Supabase
ENABLE_SUPABASE=no
SUPABASE_JWT_SECRET=<auto-generated>
SUPABASE_ANON_KEY=<auto-generated>
SUPABASE_SERVICE_ROLE_KEY=<auto-generated>

# Kokoro
ENABLE_KOKORO=no
VOICE_MODEL=whisper

# Caddy
ENABLE_CADDY=no
LETSENCRYPT_EMAIL=<your-email>

# Cloudflared
ENABLE_CLOUDFLARED=no
CLOUDFLARED_TUNNEL_TOKEN=<from-cloudflare>
```

## Integration Examples

### Langfuse Integration

```typescript
import { traceLLMCall } from '@seiling/utils/langfuseClient';

await traceLLMCall(
  'agent-workflow',
  { prompt: userInput },
  { response: aiResponse },
  { model: 'gpt-4', agent: 'eliza' }
);
```

### SearXNG Integration

```python
import requests

response = requests.get(
    'http://searxng:8080/search',
    params={'q': 'Sei Network DeFi', 'format': 'json'}
)
results = response.json()
```

### Supabase Integration

```typescript
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  'http://localhost:8000',
  process.env.SUPABASE_ANON_KEY!
);

await supabase.from('templates').insert([...]);
```

## Resource Requirements

Additional resource requirements per service:

- **Langfuse**: +4 containers, ~500MB RAM
- **Prometheus/Grafana**: +2 containers, ~300MB RAM
- **SearXNG**: +1 container, ~200MB RAM
- **Supabase**: +6 containers, ~1GB RAM
- **Kokoro/Chatterbox**: +2 containers, ~400MB RAM
- **Caddy**: +1 container, ~50MB RAM

Total: ~2.5GB RAM for all expanded capabilities.

## Troubleshooting

### Common Issues

1. **Services not starting**: Check dependencies and secrets
2. **Port conflicts**: Adjust ports in `.env`
3. **Memory issues**: Enable services incrementally
4. **Connection errors**: Verify network and dependencies

### Getting Help

- Check individual service documentation
- Review logs: `docker logs seiling-<service-name>`
- Check health status: `bash scripts/bootstrap/health_check.sh`

## Security Considerations

- All services use internal networking
- Secrets auto-generated (change for production)
- HTTPS available via Caddy
- Access control via service-specific auth
