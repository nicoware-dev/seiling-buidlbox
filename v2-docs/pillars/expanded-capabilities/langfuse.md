# Langfuse - LLM Observability

## Overview

Langfuse is an open-source LLM engineering platform that provides tracing, debugging, and monitoring capabilities for LLM calls across all Seiling Buidlbox agents (n8n, Flowise, ElizaOS, Cambrian).

## Features

- **LLM Call Tracing**: Trace all LLM calls across agents and workflows
- **Cost Tracking**: Monitor token usage and costs per agent/workflow
- **Performance Analytics**: Track latency and throughput metrics
- **Debugging Tools**: Debug prompts and responses interactively
- **Sei-Specific Metrics**: Custom metrics for Sei blockchain transactions and gas costs

## Setup

### Enable Langfuse

1. **Set environment variable in `.env`:**
   ```bash
   ENABLE_LANGFUSE=yes
   ```

2. **Generate secrets (automatically done by bootstrap):**
   ```bash
   # These are auto-generated by configure_env.sh
   LANGFUSE_NEXTAUTH_SECRET=<auto-generated>
   LANGFUSE_SALT=<auto-generated>
   LANGFUSE_ENCRYPTION_KEY=<auto-generated>
   CLICKHOUSE_PASSWORD=<auto-generated>
   MINIO_ROOT_PASSWORD=<auto-generated>
   ```

3. **Deploy services:**
   ```bash
   ./bootstrap.sh
   ```

### Services Included

Langfuse stack includes:
- **langfuse-web**: Main web UI (Port 3000 internally, 8004 via proxy)
- **langfuse-worker**: Background processing for analytics
- **clickhouse**: Analytics database for storing traces
- **minio**: S3-compatible storage for events and media

All services use shared PostgreSQL and Redis from the main Seiling Buidlbox setup.

## Access

- **Web UI**: http://localhost:8004 (if Caddy enabled) or http://localhost:3000
- **Default credentials**: Created on first login (no default credentials)

## Integration

### Using the Langfuse SDK

The Langfuse client is available in `@seiling/utils`:

```typescript
import { initLangfuseClient, traceLLMCall } from '@seiling/utils/langfuseClient';

// Initialize client
const langfuse = initLangfuseClient(
  process.env.LANGFUSE_PUBLIC_KEY!,
  process.env.LANGFUSE_SECRET_KEY!,
  'http://langfuse-web:3000'
);

// Trace an LLM call
await traceLLMCall(
  'agent-workflow',
  { prompt: userInput },
  { response: aiResponse },
  {
    model: 'gpt-4',
    agent: 'eliza',
    workflow: 'sei-transaction'
  }
);
```

### Integration with n8n

Add Langfuse tracing to n8n workflows:

1. Use the HTTP Request node to call Langfuse API
2. Or use custom n8n nodes (to be implemented)
3. Trace workflow executions automatically

### Integration with Agents

- **ElizaOS**: Instrument LLM calls in agent handlers
- **Cambrian**: Add tracing to multi-modal interactions
- **Flowise**: Trace agent execution flows

### Sei-Specific Metrics

Track blockchain-specific metrics:

```typescript
const trace = langfuse.trace({
  name: 'sei-transaction',
  metadata: {
    chainId: 'atlantic-2',
    gasUsed: '100000',
    txHash: '0x...',
    tokenAmount: '1.5 SEI'
  }
});
```

## Configuration

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `ENABLE_LANGFUSE` | Enable/disable Langfuse | `no` |
| `LANGFUSE_NEXTAUTH_SECRET` | NextAuth secret key | Auto-generated |
| `LANGFUSE_SALT` | Encryption salt | Auto-generated |
| `LANGFUSE_ENCRYPTION_KEY` | Encryption key | Auto-generated |
| `CLICKHOUSE_PASSWORD` | ClickHouse password | Auto-generated |
| `MINIO_ROOT_PASSWORD` | MinIO root password | Auto-generated |
| `LANGFUSE_PORT` | External port | `8004` |

### Docker Compose

Langfuse is configured in `docker/services/docker-compose.langfuse.yml` and follows the standard Seiling Buidlbox service pattern with:
- Shared network (`seiling_network`)
- Health checks
- Dependency management
- Enable/disable via `ENABLE_*` flag

## Troubleshooting

### Service Not Starting

1. Check logs:
   ```bash
   docker logs seiling-langfuse-web
   docker logs seiling-clickhouse
   docker logs seiling-minio
   ```

2. Verify dependencies:
   - PostgreSQL must be healthy
   - Redis must be healthy

3. Check secrets:
   - Ensure all secrets are generated in `.env`

### Connection Issues

1. Verify network connectivity:
   ```bash
   docker network inspect seiling-buidlbox_seiling_network
   ```

2. Check service dependencies:
   - All dependent services must be healthy before Langfuse starts

## Performance

- **Overhead**: <5% latency overhead when tracing enabled
- **Storage**: ClickHouse and MinIO provide efficient storage
- **Scalability**: Handles high-volume tracing with background workers

- **Authentication**: NextAuth-based authentication
- **Encryption**: All sensitive data encrypted
- **Network**: Services only expose ports internally (via Docker network)
