# Supabase - Backend-as-a-Service

## Overview

Supabase provides a complete Backend-as-a-Service (BaaS) stack including PostgreSQL database, authentication, storage, realtime subscriptions, and admin UI. In Seiling Buidlbox, it enables user management, template storage, and real-time updates across services.

## Features

- **PostgreSQL Database**: Full-featured relational database
- **Authentication**: User authentication with JWT
- **Storage**: File storage with S3-compatible API
- **Realtime**: Real-time subscriptions and updates
- **Studio**: Admin UI for database management
- **API Gateway**: Kong-based API gateway for all services

## Setup

### Enable Supabase

1. **Set environment variables in `.env`:**
   ```bash
   ENABLE_SUPABASE=yes
   SUPABASE_DB_PASSWORD=<auto-generated or custom>
   SUPABASE_JWT_SECRET=<auto-generated>
   SUPABASE_ANON_KEY=<auto-generated>
   SUPABASE_SERVICE_ROLE_KEY=<auto-generated>
   SUPABASE_DASHBOARD_USERNAME=admin
   SUPABASE_DASHBOARD_PASSWORD=<auto-generated>
   SUPABASE_POOLER_TENANT_ID=<auto-generated>
   ```

2. **Deploy services:**
   ```bash
   ./bootstrap.sh
   ```

### Services Included

Supabase stack includes:
- **supabase-db**: PostgreSQL database (Port 5432 internally)
- **supabase-kong**: API gateway (Port 8000)
- **supabase-auth**: Authentication service (Port 9999 internally)
- **supabase-storage**: File storage service (Port 5000 internally)
- **supabase-realtime**: Realtime subscriptions (Port 4000 internally)
- **supabase-studio**: Admin UI (Port 3000 internally, 8007 via proxy)

## Access

- **Supabase Studio**: http://localhost:8007 (if Caddy enabled) or http://localhost:3000
- **API Gateway**: http://localhost:8000
- **Database**: localhost:5433 (if port exposed)

## Integration

### Using the Supabase Client

**JavaScript/TypeScript:**
```typescript
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  'http://localhost:8000',
  process.env.SUPABASE_ANON_KEY!
)

// Insert data
const { data, error } = await supabase
  .from('templates')
  .insert([{ 
    user_id: userId,
    name: 'My Workflow',
    data: workflowJson
  }])

// Query data
const { data: templates } = await supabase
  .from('templates')
  .select('*')
  .eq('user_id', userId)

// Real-time subscriptions
supabase
  .channel('agents')
  .on('postgres_changes', 
    { event: 'INSERT', schema: 'public', table: 'agents' },
    (payload) => console.log('New agent:', payload.new)
  )
  .subscribe()

// File storage
const { data: fileData, error: uploadError } = await supabase.storage
  .from('templates')
  .upload('my-workflow.json', file)
```

### Authentication

**User sign-up:**
```typescript
const { data, error } = await supabase.auth.signUp({
  email: 'user@example.com',
  password: 'secure-password'
```


### Database Setup

1. Access Supabase Studio at http://localhost:3000
2. Login with admin credentials
3. Create tables and schemas
4. Set up Row Level Security (RLS) policies

### Row Level Security (RLS)

Enable RLS for data security:

```sql
-- Enable RLS on a table
ALTER TABLE templates ENABLE ROW LEVEL SECURITY;

-- Create policy
CREATE POLICY "Users can view own templates"
ON templates FOR SELECT
USING (auth.uid() = user_id);
```

## Troubleshooting

### Services Not Starting

1. Check logs:
   ```bash
   docker logs seiling-supabase-db
   docker logs seiling-supabase-kong
   docker logs seiling-supabase-auth
   ```

2. Verify dependencies:
   - Database must be healthy before other services
   - Kong must be healthy before Studio

3. Check secrets:
   - Ensure all secrets are generated in `.env`
   - Verify JWT secret format

### Connection Issues

1. Verify network connectivity:
   ```bash
   docker network inspect seiling-buidlbox_seiling_network
   ```

2. Check service dependencies:
   - All services depend on database
   - Studio depends on Kong

### Database Migration

Run migrations via Studio or SQL:

```sql
-- Example migration
CREATE TABLE IF NOT EXISTS templates (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users(id),
  name TEXT NOT NULL,
  data JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);
```
