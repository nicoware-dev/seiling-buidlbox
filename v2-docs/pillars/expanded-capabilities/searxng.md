# SearXNG - Privacy-Focused Meta-Search

## Overview

SearXNG is a privacy-respecting, hackable metasearch engine that aggregates results from multiple search engines without tracking users. In Seiling Buidlbox, it's enhanced with Sei-specific search engines (SeiScan, SeiTrace) for blockchain-focused searches.

## Features

- **Privacy-Focused**: No user tracking or profiling
- **Multi-Engine Aggregation**: Searches across Google, Bing, DuckDuckGo, and more
- **Sei-Specific Engines**: Custom engines for SeiScan and SeiTrace
- **API Access**: JSON API for programmatic access
- **Fast Results**: <100ms query response times

## Setup

### Enable SearXNG

1. **Set environment variable in `.env`:**
   ```bash
   ENABLE_SEARXNG=yes
   SEARXNG_SECRET_KEY=<auto-generated>
   SEARXNG_BASE_URL=http://localhost:8080/
   ```

2. **Deploy service:**
   ```bash
   ./bootstrap.sh
   ```

### Configuration

SearXNG is configured via `docker/searxng/settings.yml` with:
- Default search engines (Google, Bing, DuckDuckGo)
- Sei-specific engines (SeiScan, SeiTrace)
- UI customization options

The secret key is set via the `SEARXNG_SECRET_KEY` environment variable (auto-generated by bootstrap).

## Access

- **Web UI**: http://localhost:8006 (if Caddy enabled) or http://localhost:8080
- **API**: http://localhost:8080/search?q=query&format=json

## Integration

### Using the SearXNG API

**Python Example:**
```python
import requests

def search_web(query, format='json'):
    """Search using SearXNG"""
    url = 'http://searxng:8080/search'
    params = {
        'q': query,
        'format': format
    }
    response = requests.get(url, params=params)
    return response.json()

# Example usage
results = search_web('Sei Network DeFi protocols')
for result in results.get('results', []):
    print(f"{result['title']}: {result['url']}")
```

**JavaScript/TypeScript Example:**
```typescript
async function searchWeb(query: string): Promise<any> {
  const response = await fetch(
    `http://searxng:8080/search?q=${encodeURIComponent(query)}&format=json`
  );
  return response.json();
}

// Example usage
const results = await searchWeb('Sei Network NFT marketplace');
```

### Integration with n8n

Use the HTTP Request node in n8n to call SearXNG:

1. Create HTTP Request node
2. Set method to GET
3. URL: `http://searxng:8080/search`
4. Query parameters:
   - `q`: Search query
   - `format`: `json`

### Integration with OpenWebUI

Add SearXNG as a function in OpenWebUI:

```python
def search_sei_network(query):
    """Search function for OpenWebUI"""
    import requests
    url = 'http://searxng:8080/search'
    params = {'q': query, 'format': 'json'}
    response = requests.get(url, params=params)
    results = response.json().get('results', [])
    return '\n'.join([f"- {r['title']}: {r['url']}" for r in results[:5]])
```

### Sei-Specific Search

SearXNG includes shortcuts for Sei-specific searches:

- `sc:` - Search SeiScan (e.g., `sc: sei network transactions`)
- `st:` - Search SeiTrace (e.g., `st: sei network analytics`)

## Configuration

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `ENABLE_SEARXNG` | Enable/disable SearXNG | `no` |
| `SEARXNG_SECRET_KEY` | Secret key for SearXNG | Auto-generated |
| `SEARXNG_BASE_URL` | Base URL for SearXNG | `http://localhost:8080/` |
| `SEARXNG_PORT` | External port | `8006` |

### Settings Configuration

Edit `docker/searxng/settings.yml` to customize:
- Search engines
- UI theme
- Result formats
- Custom engine configurations

### Adding Custom Engines

Add Sei-specific engines in `settings.yml`:

```yaml
engines:
  - name: seiscan
    engine: google
    shortcut: sc
    base_url: https://seiscan.app
  - name: seitrace
    engine: google
    shortcut: st
    base_url: https://seitrace.io
```

## Troubleshooting

### Service Not Starting

1. Check logs:
   ```bash
   docker logs seiling-searxng
   ```

2. Verify configuration:
   - Check `docker/searxng/settings.yml` exists
   - Verify secret key is set

3. Check network connectivity:
   - Ensure service can reach external search engines

### Search Results Not Appearing

1. Check engine status:
   - Access http://localhost:8080/preferences
   - Verify engines are enabled

2. Check network:
   - Some search engines may block requests
   - Try different engines

### Performance Issues

1. Enable Redis caching (if available)
2. Reduce number of engines
3. Increase timeout values in settings

## Security

- **Privacy**: No user tracking or data collection
- **Network**: Service only exposes port internally
- **HTTPS**: Use Caddy or Traefik for HTTPS termination

## Performance

- **Query Time**: <100ms for most queries
- **Caching**: Optional Redis caching support
- **Concurrent Requests**: Handles multiple simultaneous searches
