# Seiling Buidlbox v2 Roadmap

## Overview
18-month plan (Q1 2025 - Q2 2026) across three phases: Foundation (core infra), Features & DX (user tools), Ecosystem Growth (community/monetization). Aligned to five pillars; budget $500K total (40% dev, 30% community, 20% marketing, 10% ops). Success Metrics: 10K users, 1K contribs, $1M TVL in token economy. Risks: Tech debt (mitigate CI/CD), adoption (hackathons).

## Phase 1: Foundation (Q1-Q2 2025, $200K)
Focus: Stable base with expanded capabilities and improved DX.
- **Expanded Capabilities** (60%): Integrate Langfuse/Supabase/SearXNG; MCP v2 upgrade; basic observability (Prometheus).
- **Improved DX** (30%): Template store MVP, quick demo, Windows support, core tutorials.
- **Community Focus** (10%): Launch bounty program, basic incentives.
- Milestones: v2.0 release (core services toggleable), 500 beta users.
- Deliverables: Docker bundles, bootstrap enhancements, initial docs.

## Phase 2: Features & DX (Q3-Q4 2025, $150K)
Focus: User-facing tools and education.
- **New Feature Development** (50%): Captain UI, Builder no-code, OS workspace MVP, Auditor beta.
- **Improved DX** (30%): Full tutorials/videos, AI dev resources, template expansion (20+).
- **Expanded Capabilities** (20%): Voice (Kokoro), proxies (Caddy), Coolify deploys.
- Milestones: v2.1 (UIs live), 2K users, first mini-hackathon.
- Deliverables: UIs in packages/, interactive docs, community templates.

## Phase 3: Ecosystem Growth (Q1-Q2 2026, $150K)
Focus: Community and sustainability.
- **Community Focus** (40%): Gamification/NFTs, full DAO (Snapshot/Aragon), hackathons quarterly.
- **Sustainable Growth** (30%): Token launch (SEILING), subs/premium, services marketplace.
- **New Feature Development** (20%): Auditor full, OS advanced (multi-agent).
- **Expanded Capabilities** (10%): Full observability (Grafana dashboards), advanced search.
- Milestones: v2.2 (DAO-integrated), 10K users, $500K token TVL.
- Deliverables: Governance docs, marketplace UI, tokenomics whitepaper.

## Pillar Cross-Cut
- **Budget Allocation**: Expanded 30%, New Features 25%, Improved DX 20%, Community 15%, Sustainable 10%.
- **Metrics**: User growth (monthly), contribs (PRs/bounties), revenue (subs/tokens).
- **Risks/Contingencies**: Delays (parallel teams), market (Sei focus first).

This roadmap positions v2 as Sei\'s premier AI dev platform.
